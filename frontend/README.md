# SpecPilot 프론트엔드

기획서와 소스코드를 올려 분석을 돌리고(백엔드 시연 서버), 백엔드가 만든 결과 파일을 읽어 요구사항별 구현 상태와 테스트 사양서를 검토하는 웹 화면. 로컬 시연용이다.

## 설치와 실행

**Node.js 22.12 이상**이 필요하다. 명령은 모두 `frontend` 폴더에서 한다.

```bash
cd frontend
npm ci          # 처음 한 번 (인터넷 필요)
npm run dev     # 터미널에 찍힌 주소를 연다
```

## 결과 파일 두는 곳

```
backend/output/<실행ID>/          ← 조장 PC: 백엔드 결과를 그대로 읽는다 (복사할 필요 없음)
frontend/local/runs/<실행ID>/     ← 다른 PC: 조장의 backend/output/<실행ID>/ 폴더를 통째로
frontend/local/code/<샘플코드>/   ← 다른 PC에서 "코드 앞뒤 보기"용 (선택)
```

- 두 곳의 실행을 합쳐 최근 것부터 보여 준다. 같은 실행 ID가 두 곳에 있으면 `local/runs/` 것을 쓴다.
- 폴더 이름은 실행 ID 그대로 둔다. 한글·공백이 들어가면 목록에 나오지 않는다.
- 조장 PC에서는 원래 코드 위치(`judge/run.json`의 `code_root`)를 그대로 찾으므로 `local/code/`에 넣지 않아도 된다.
- 둘 다 비어 있으면 가짜 예시 데이터(`mock/`)가 보인다. 예시 데이터로 기획서 페이지까지 보려면 `python mock/make_mock_pdf.py`로 예시 PDF를 만든다 (Chrome·Edge 필요).
- `local/`, `backend/output/`은 기업 자료라 git에 올라가지 않는다. 커밋 전에 `git status`로 한 번 더 확인한다.

## 실제 시연 (조장 PC)

웹에서 기획서와 코드를 올리면 백엔드 시연 서버가 ①~④를 실제로 돌린다. 터미널 두 개를 연다.

1. 터미널 1 (`backend` 폴더): `python -m specpilot serve`
   - 처음 한 번 `pip install -r requirements.txt`. API 키는 `backend/.env`
2. 터미널 2 (`frontend` 폴더): 처음 한 번 `npm ci`, 그다음 `npm run dev`
3. 터미널 2에 찍힌 주소로 들어가 "새로 분석하기"
   - 프로젝트 이름, 기획 문서 PDF(여러 개면 올린 순서대로 이어 붙인다), 소스코드 zip(또는 저장소 주소)을 넣고 "분석 시작"
   - 진행 화면: 입력 점검 → ① → ② 화면별 → ③ 화면별 → ④ 화면 묶음별. 기획서 화면 수에 따라 수십 분 걸린다. 창을 닫아도 서버에서 계속 돌고, 시작 화면의 "진행 화면 보기"로 돌아온다
   - 끝나면 "결과 보기"
4. 결과 확인
   - 요약 → 화면 카드 → 화면별 보기: 기획서 페이지의 원문 자리에 판정 색 형광펜이 맞게 칠해지는지
   - 요구사항 표, 코드 보기, 테스트 사양서(기업 양식 미리보기), 상단 "내보내기"(엑셀 5종)

- 명령어로 돌려 둔 결과도 "최근 분석"에 바로 보인다. ④를 안 돌린 실행은 `python -m specpilot scenario --run output/<실행ID>`로 사양서를 만든다.
- 시연 서버가 꺼져 있으면 업로드는 흉내만 낸다: 파일을 보내지 않고, 가장 최근 결과를 단계별로 보여 준다 (개발 중 화면 확인용).
- 한 번에 하나만 돌린다. 진행 중에 또 올리면 "다른 분석이 진행 중입니다"가 나온다.

이상한 곳이 있으면 **어느 화면인지와 캡처**를 프론트 담당에게 보낸다. 아래 "아직 없는 것"은 문제가 아니다.

## 화면

| 주소 | 화면 |
| --- | --- |
| `/` | 시작, 최근 분석 |
| `/new`, `/progress` | 업로드, 분석 진행 |
| `/summary` | 요약 |
| `/screen/:id` | 화면별 보기 (기획서 페이지 + 형광펜 + 판정 카드) |
| `/table` | 요구사항 표 |
| `/spec` | 테스트 사양서 |

상단 "내보내기"에서 엑셀 5종을 내려받는다. 테스트 사양서와 추적표는 백엔드가 만든 엑셀(기업 양식 서식 포함)을 그대로 내려받고, 나머지 3종(구현 체크리스트, 정합성 판정 결과, 질문 시트)은 브라우저에서 만든다. 백엔드 사양서가 없는 실행(예시 데이터)은 사양서도 브라우저에서 만든다.

## 서버와 주고받는 것

- 결과 파일: Vite 개발 서버의 `/data` 미들웨어(`vite-local-runs.ts`)
- 새 분석·진행 상태: `/api`를 백엔드 시연 서버(`http://127.0.0.1:8765`, `vite.config.ts`의 proxy)로 넘긴다. 주소와 형식은 `src/api/api.ts` 주석과 `src/types/progress.ts`

## 아직 없는 것

- 진행 중인 분석 취소
- 실패한 분석의 결과를 진행 화면에서 바로 열기 (②까지 끝났으면 시작 화면 "최근 분석"에서 열 수 있다)
