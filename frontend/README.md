# SpecPilot 프론트엔드

백엔드가 만든 결과 파일을 읽어서, 요구사항별 구현 상태를 검토하는 웹 화면. 로컬 시연용이다.

## 설치와 실행

**Node.js 22.12 이상**이 필요하다. 명령은 모두 `frontend` 폴더에서 한다.

```bash
cd frontend
npm ci          # 처음 한 번 (인터넷 필요)
npm run dev     # 터미널에 찍힌 주소를 연다
```

## 결과 파일 두는 곳

```
frontend/local/runs/<실행ID>/     ← 조장의 backend/output/<실행ID>/ 폴더를 통째로
frontend/local/code/<샘플코드>/   ← "코드 앞뒤 보기"용 (선택)
```

- `local/runs/`가 비어 있으면 가짜 예시 데이터(`mock/`)가 보인다.
- `local/`은 기업 자료라 git에 올라가지 않는다. 커밋 전에 `git status`로 한 번 더 확인한다.

## 화면

| 주소 | 화면 |
| --- | --- |
| `/` | 시작, 최근 분석 |
| `/new`, `/progress` | 업로드, 분석 진행 |
| `/summary` | 요약 |
| `/screen/:id` | 화면별 보기 (기획서 페이지 + 형광펜 + 판정 카드) |
| `/table` | 요구사항 표 |
| `/spec` | 테스트 사양서 |

상단 "내보내기"에서 엑셀 4종을 내려받는다.

## 아직 없는 것

- **업로드 → 실제 분석**: 지금은 흉내다. 백엔드를 실행할 로컬 서버가 생기면 `src/api/api.ts`만 바꾼다.
- **테스트 사양서(④)**: 백엔드에 아직 없어서 실제 결과에서는 비어 있다.
