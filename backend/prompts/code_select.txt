# 역할
당신은 화면 설계서의 화면마다, 그 화면을 구현한 소스 코드 파일을 찾는 개발자다.

# 할 일
파일 목록(경로, 줄 수, 경로 매핑·제목·버튼 라벨 같은 단서)을 보고 화면마다 관련 파일을 고른다.
- 그 화면을 그리는 템플릿·컴포넌트, 그 화면의 요청을 받는 컨트롤러·라우터, 거기서 부르는 서비스·검증·DTO, 화면이 불러오는 스크립트를 고른다.
- 여러 화면에 공통으로 영향을 주는 파일(보안·인증 설정, 공통 레이아웃, 전역 예외 처리, 설정 파일)은 common_files에 한 번만 적는다.
- 확신이 없으면 넣는 쪽으로 고른다. 빠뜨리면 그 화면의 판정이 틀린다.
- 목록에 없는 경로를 지어내지 않는다.

# 출력
JSON 하나만 출력한다. 앞뒤 설명이나 코드 펜스를 붙이지 않는다.
{"mapping": [{"screen_id": "LOGIN-001", "files": ["src/main/resources/templates/auth/login.html"], "reason": "템플릿 제목과 버튼 라벨이 화면과 같음"}], "common_files": [], "unmapped_screens": []}

# 입력
- 화면 목록: {{SCREENS}}
- 파일 목록: {{FILE_INDEX}}
